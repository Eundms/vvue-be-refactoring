# Vvue 도메인

## 개요

- 쀼는 커플이 함께 일정을 관리하고 추억을 기록하는 온라인 서비스이다
- 쀼는 커플이 함께 만들어가는 추억을 체계적으로 정리하고, 시간이 지나도 쉽게 되돌아볼 수 있게 돕는 것을 목표로 한다

## 회원과 커플

- 쀼에서 활동하기 위해서는 회원으로 가입해야 한다
    - 회원은 구글이나 카카오 계정으로 소셜 로그인을 통해 가입한다
    - 로그인 후 닉네임, 생년월일, 성별, 프로필 사진을 등록하면 가입이 완료된다
- 가입한 회원은 상대방과 커플로 연결될 수 있다
    - 커플 연결을 위해서는 초대 코드가 필요하다
    - 한 회원이 초대 코드를 생성하고, 상대방이 이 코드를 입력하면 두 사람이 커플(Married)로 연결된다
    - 한 명의 회원은 한 명의 상대방하고만 커플이 될 수 있다
    - 커플로 연결되면 결혼기념일과 커플 프로필 사진을 등록할 수 있다

## 일정 관리

- 커플로 연결된 두 사람은 공유 일정을 만들고 관리할 수 있다
    - 일정은 날짜와 제목으로 구성된다
    - 일정은 커플 단위로 관리되어, 둘 중 누가 만들든 상대방도 똑같이 볼 수 있다
- 일정은 반복 주기를 설정할 수 있다
    - 반복 주기: 없음, 매년, 매월 등
    - 결혼기념일이나 생일 같은 중요한 날은 매년 자동으로 반복되도록 설정된다
- 일정은 타입을 가진다
    - 일반 일정, 결혼기념일, 상대방 생일, 내 생일 등으로 구분된다

## 추억 기록

- 일정이 끝나면 그날의 추억을 기록할 수 있다
    - 하나의 일정에 대해 하나의 일정 추억(ScheduleMemory)을 작성한다
    - 일정 추억은 제목과 내용으로 구성된다
- 하나의 일정에는 여러 장소를 방문할 수 있다
    - 각 장소마다 장소 추억(PlaceMemory)을 별도로 기록한다
    - 예: "강남 데이트" 일정에서 카페, 식당, 영화관을 갔다면 세 개의 장소 추억을 작성
- 장소 추억은 평점, 코멘트, 사진으로 구성된다
    - 평점은 0.0에서 5.0 사이의 값이다
    - 하나의 장소 추억에 여러 장의 사진을 첨부할 수 있다
- 추억 구조는 계층적으로 구성된다
    - 일정 → 장소별 추억 → 사진 순서로 계층이 나뉜다
    - 이를 통해 "2024년 1월 강남 데이트 때 갔던 그 카페"처럼 구체적으로 추억을 찾을 수 있다

## 장소 정보

- 장소는 실제 존재하는 식당, 카페, 관광지 등의 정보를 담고 있다
    - 장소 정보는 카카오맵 API와 연동되어 자동으로 가져온다
    - 장소는 카카오맵의 Place ID를 그대로 사용한다
- 장소는 다음 정보를 포함한다
    - 장소명, 주소, 도로명 주소, 전화번호
    - 카테고리 정보 (예: 음식점 > 한식 > 김치찌개)
    - 좌표 정보 (위도, 경도)
    - 카카오맵 URL
- 커플은 자주 가는 장소를 즐겨찾기에 추가할 수 있다
    - 즐겨찾기는 커플 단위로 관리된다

## 사진 관리

- 모든 사진은 AWS S3에 저장되고 CloudFront를 통해 제공된다
    - 보안을 위해 서명된 URL을 사용한다
    - 권한이 있는 사용자만 사진을 볼 수 있다
- 사진은 용도별로 분류된다
    - 회원 프로필 사진
    - 커플 프로필 사진
    - 장소 추억 사진
- 사진은 접근 권한 레벨을 가진다
    - PUBLIC: 누구나 접근 가능
    - PRIVATE: 권한이 있는 사용자만 접근 가능

## 알림 시스템

- 상대방의 활동에 대해 실시간 알림을 받을 수 있다
    - 상대방이 새로운 일정을 만들면 알림
    - 상대방이 추억을 추가하면 알림
    - 커플 초대를 받으면 알림
- 알림은 Firebase Cloud Messaging을 통해 모바일 기기로 전송된다
- 알림은 읽음/안읽음 상태를 관리한다
- 알림은 타입별로 구분된다
    - 일정 생성, 추억 추가, 커플 초대, 장소 공유 등

## 데이터 격리와 보안

- 모든 일정과 추억은 커플 단위로 관리된다
    - 각 커플의 데이터는 완전히 분리되어 있다
    - 다른 커플의 추억은 절대 볼 수 없다
- 사진은 서명된 URL로 보호된다
    - URL은 시간 제한이 있어 일정 시간이 지나면 만료된다
- API 접근은 JWT 토큰으로 인증된다
    - Access Token과 Refresh Token을 사용한다
